服务端入口 = 中继拨号到的服务端网关通道；本地路由 = 你的程序要连的地址(:端口[/路径]，绑 127.0.0.1)。连接/流入/流出为实时指标。

证书选择

选一枚证书并验证：普通证书 → 显示"新增隧道"；admin 证书 → 显示"证书管理"。未选证书前两者都不可用。

新增隧道

先在下方案例"证书选择"卡里选证书并验证，服务列表才会加载。选中服务后，其每个通道一行，填本地路由(默认=服务端通道原样, 含冒号; 可带路径)。

服务端配置

mutable=改后落盘 / ephemeral=仅内存 / immutable=只读(灰显, 服务端拦截修改)。改动后点底部保存统一生效(热重载)。
